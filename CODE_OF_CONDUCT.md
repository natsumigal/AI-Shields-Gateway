# Code Of Conduct

This project follows a simple standard: be respectful, constructive, and practical.

Good participation means:

- explain ideas clearly
- assume good intent
- disagree with technical reasoning, not personal attacks
- keep issues and pull requests focused
- remember that this project is for learning and real-world improvement

Unacceptable behavior includes harassment, threats, hate speech, personal attacks, and intentionally sharing secrets or harmful data.

Maintainers may remove comments, close issues, or block contributors who make the project unsafe or unwelcoming.
