# Roadmap

This project should stay useful as both a learning reference and a production foundation.

## Phase 1: Gateway Foundation

- request validation
- risk scoring
- allow/block/human-review policy
- OpenAI connector
- output filtering
- audit trail
- framework mappings
- tests and Swagger examples

Status: in progress, useful as a reference implementation.

## Phase 2: Production Hardening

- JWT authentication
- role-based authorization
- tenant isolation
- persistent audit storage
- rate limiting and quotas
- structured error responses
- OpenTelemetry traces
- Docker image publishing

## Phase 3: Governance Records

- model inventory
- AI use case register
- risk assessment records
- control ownership
- evidence records
- vendor records
- incident records

## Phase 4: Compliance Operations

- framework coverage API
- evidence expiry
- approval workflow
- report export
- dashboard backend endpoints

## Phase 5: Evaluation And Red Teaming

- prompt injection test sets
- harmful content tests
- sensitive data leakage tests
- bias and discrimination tests
- model/provider comparison records
